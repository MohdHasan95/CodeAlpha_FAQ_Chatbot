# CodeAlpha FAQ Chatbot

A Python FAQ chatbot for CodeAlpha AI Internship Task 2.

## Features
- Streamlit chat interface
- FAQ knowledge base
- TF-IDF text vectorization
- Cosine similarity question matching
- Fallback response for unrelated questions

## Setup
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Files
- `app.py`: chatbot interface and matching logic
- `faq_data.py`: FAQ questions and answers
- `requirements.txt`: dependencies

The FAQ knowledge base is based on the CodeAlpha AI internship task instructions.
